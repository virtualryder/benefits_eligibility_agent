# Synthetic Benefits Demo Dataset (12 cases)
All records are fictional. SSNs use the 900- range (never issued by SSA). Built 2026-08-23 to demo the
Aegis-governed benefits-eligibility agent: mix of ELIGIBLE / INELIGIBLE / NEEDS_REVIEW so the demo shows
allow paths, the human gate, and PII masking on realistic-shaped (but fake) data. Mirrors the pattern of
EDU_financial_aid_agent/data/synthetic. Use with demo_extra.sh payload shapes.
